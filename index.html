Web SIG - PNR du Mont-Ventoux

Interface Web SIG développée dans le cadre du Master GEOTER, Avignon Université. Objectif : visualiser les résultats des méthodes automatisées d'identification des terrasses en pierres sèches sur le territoire du PNR du Mont-Ventoux.

Barre d'outils

Accueil Navigation Distance Surface Coordonnées Ma position Plein écran Export Terrasses

Échap navigation · D distance · A surface · X coordonnées · L localiser · N nuit · Clic droit menu contextuel

Vue comparateur

Activez le toggle Vue comparateur dans le panneau. Choisissez un fond de carte différent à gauche et à droite. La couleur des communes et de l'emprise s'adapte à chaque côté. Le séparateur est glissable.

Profil altimétrique

L'outil Distance génère automatiquement un profil en travers (altitude relative au point de départ). Exportable en PNG.

Couches

Activez les couches via le panneau gauche. Ajustez l'opacité avec le curseur. Personnalisez les couleurs avec le crayon. Réorganisez l'ordre via l'onglet Ordre.

Fonds de carte

Esri Light · Google Satellite · OpenStreetMap
Chacun adapte automatiquement la symbologie des communes et de l'emprise PNR.

Clustering dynamique

Les couches Terrasses et Ruptures contiennent un très grand nombre d'entités. Un regroupement dynamique s'active aux petites échelles (zoom < 14) :

  • Vert = groupe de terrasses
  • Jaune = groupe de ruptures
  • Zoomez au niveau 14+ pour les géométries réelles

Mode nuit

Active un thème sombre pour une utilisation terrain la nuit. La préférence est mémorisée entre les sessions. Raccourci : N.
