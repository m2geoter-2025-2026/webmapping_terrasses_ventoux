Web SIG - PNR du Mont-Ventoux

Interface Web SIG développée dans le cadre du Master GEOTER d'Avignon Université.

Objectif : visualiser les résultats des méthodes automatisées utilisées pour l'identification des terrasses en pierres sèches sur le territoire du PNR du Mont-Ventoux.

Couches

Activez les couches via le panneau gauche. Ajustez opacité et couleurs. Réorganisez l'ordre via l'onglet « Ordre ».

Outils

Distance Surface Coordonnées Capture

Échap pour annuler l'outil actif · Clic droit pour le menu contextuel

Profil en travers

L'outil Distance génère automatiquement un profil altimétrique en référentiel local (altitude relative au point de départ).

Fonds de carte

Esri Light · Google Satellite · OpenStreetMap

Cercles colorés sur la carte

Les couches Terrasses et Ruptures de pentes contiennent un très grand nombre d'entités. Pour garantir la fluidité de navigation, un système de regroupement dynamique (clustering) est activé aux petites échelles (zoom < 14) :

  • Cercle rouge = groupe de terrasses — le chiffre indique le nombre d'entités regroupées
  • Cercle orange = groupe de ruptures de pentes
  • Zoomez au niveau 1 → 14 pour afficher les géométries réelles
